What's new in PaintNode 0.2.7

- Added Ubuntu x86_64 `.deb` and AppImage builds, including the desktop-menu launcher and high-resolution application icons.
- Added PaintNode-managed Codex and Claude runtime packages for Linux x86_64, with manifest and checksum preflight checks before an app release can publish.
- Isolated Apple-only native integrations so the Tauri backend builds and runs on Linux.
- Displayed host-native keyboard shortcut labels on Linux and Windows while preserving macOS glyphs.
- Added native Linux CI, Debian package validation, and an atomic Linux release workflow.
- Moved updater and managed-runtime downloads to the independently maintained `Emilio-01-T/paintnode` release channel.
- Kept macOS downloads on the original White Cornerstone release channel.
